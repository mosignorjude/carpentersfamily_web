# Cloudflare R2 Receipt Uploads Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace typed payment references with required receipt uploads for paid bank transfers, stored privately in Cloudflare R2 and recorded atomically with the financial row.

**Architecture:** Upload the validated file to R2 first, then commit the financial row and `finance_receipts` metadata in one security-definer RPC. Every read goes through an authenticated Next.js proxy that re-checks access and SHA-256. Payment methods collapse to `bank_transfer` and `cash`; methods become immutable after entry. The five entry flows (club, event income/expense, event ticket sale, member dues request, direct officer dues entry) share one orchestrated path.

**Tech Stack:** Next.js 16.4.3 App Router, React 19.3.1, server actions, Supabase Postgres/RLS/pgTAP, `@aws-sdk/client-s3`, `pdfjs-dist`, Node `--test` with `.mjs`.

**Spec:** `docs/superpowers/specs/2026-10-25-r2-receipts-design.md`

## Global Constraints

- Receipt required **iff** `payment_method = 'bank_transfer' AND payment_status = 'paid'`.
- No receipt for `cash`; no receipt for bank transfers entered as `pending`, `unpaid`, or `deposit`.
- New writes accept only `bank_transfer` and `cash`. Historical retired values stay read-only.
- Payment method is immutable after entry. Corrections/edits cannot change it; void/reverse and re-enter instead.
- R2 credentials are server-only. Never use a `NEXT_PUBLIC_` prefix, a public bucket URL, CORS, or presigned URLs.
- All receipt reads and writes go through the app server. The bucket stays private.
- All SQL functions are `security definer`, `set search_path = ''`, and validate every parameter.
- Drop old function signatures before creating new ones; Postgres overload ambiguity is a bug.
- Test-first: write the failing test, run it, implement, run it green, commit.
- Do not rewrite historical text that already contains `(Ref: ...)`.
- Do not touch unrelated uncommitted work in the repository.
- Local DB workflow: `npx supabase start`, `npx supabase db reset`, `npx supabase test db`.
- Browser verification uses a production build on `127.0.0.1:3001`.

## Documented Deviations From the Spec

These are deliberate, evidence-based changes. Each is implemented below.

1. **Four migrations instead of one.** The spec asked for a single migration. Four ordered migrations (`20261025120000`–`20261025123000`) are applied together in one release. Reason: each schema/RPC stage is independently testable and reviewable; a single 1,500-line migration cannot be validated step-by-step.
2. **`append_event_finance_audit` already has a ticket-sale branch.** Migration `20261003102501` lines 467 already resolves `event_ticket_sale`. The plan only removes the retired `event_financial_receipt` branch.
3. **The payment-status selector and event correction modal do not exist.** `recordEventFinancialTransactionAction` hard-codes `payment_status: "paid"` from the UI, and `correctEventFinancialTransactionAction` is unused. This plan adds both so pending → paid is reachable and the receipt-on-transition rule is real.
4. **`NOT VALID` checks allow `NULL`.** A bare two-value check would fail when a legacy `NULL`-method row is later updated. The checks are `payment_method is null or payment_method in ('bank_transfer','cash')` and the RPCs require a non-null value for every new write.
5. **Preflight idempotency uses a new read-only RPC.** `idempotency_key` is not selectable by `authenticated`. `find_finance_entry_id` returns only the caller's own row, letting the action skip an upload on replay. The action then calls the entry RPC with null receipt metadata so the RPC can still reject a different-value replay with `23505`.
6. **The orchestrator is `.mjs`.** The project tests TypeScript by transpiling import-free files to data URLs; aliased imports cannot resolve there. `receipt-entry.mjs` is directly importable by `node --test`, and the validator is injected.

```js
export const RECEIPT_SCOPES = ["club", "event", "event_ticket", "dues"];

const EXTENSIONS = new Map([
  ["application/pdf", "pdf"],
  ["image/jpeg", "jpg"],
  ["image/png", "png"],
]);

const UUID_PATTERN =
  /^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$/i;

export function receiptExtensionFor(contentType) {
  return EXTENSIONS.get(contentType) ?? null;
}

export function receiptRequirement(paymentMethod, paymentStatus, options = {}) {
  const { hasReceipt = false, allowLegacyMethod = false } = options;
  if (paymentMethod !== "bank_transfer") {
    if (paymentMethod === "cash") return "forbidden";
    return allowLegacyMethod ? "forbidden" : "unsupported";
  }
  if (paymentStatus !== "paid") return "forbidden";
  return hasReceipt ? "forbidden" : "required";
}

export function buildReceiptObjectKey({
  scope,
  targetId,
  receiptId,
  contentType,
}) {
  if (!RECEIPT_SCOPES.includes(scope)) {
    throw new Error("Unknown receipt scope.");
  }
  if (!UUID_PATTERN.test(targetId) || !UUID_PATTERN.test(receiptId)) {
    throw new Error("Receipt target and receipt IDs must be UUIDs.");
  }
  const extension = receiptExtensionFor(contentType);
  if (!extension) throw new Error("Unsupported receipt content type.");
  return `receipts/${scope}/${targetId}/${receiptId}.${extension}`;
}
```

```js
export function resolveR2Config(env = process.env) {
  const accountId = env.R2_ACCOUNT_ID?.trim();
  const accessKeyId = env.R2_ACCESS_KEY_ID?.trim();
  const secretAccessKey = env.R2_SECRET_ACCESS_KEY?.trim();
  const bucketName = env.R2_BUCKET_NAME?.trim();
  const endpointOverride = env.R2_ENDPOINT?.trim();

  if (!accountId || !accessKeyId || !secretAccessKey || !bucketName) {
    return null;
  }

  const endpoint =
    endpointOverride || `https://${accountId}.r2.cloudflarestorage.com`;
  try {
    const parsed = new URL(endpoint);
    if (parsed.protocol !== "https:") return null;
  } catch {
    return null;
  }

  return { accountId, accessKeyId, secretAccessKey, bucketName, endpoint };
}
```

Create `src/lib/r2/client.ts`:

```ts
import "server-only";

import { S3Client } from "@aws-sdk/client-s3";
import { resolveR2Config } from "@/lib/r2/config.mjs";

let cached: { key: string; client: S3Client } | null = null;

export function isReceiptStorageConfigured() {
  return resolveR2Config() !== null;
}

export function getReceiptBucketName() {
  return resolveR2Config()?.bucketName ?? null;
}

export function getReceiptStorageClient() {
  const config = resolveR2Config();
  if (!config) return null;

  const key = `${config.endpoint}|${config.accessKeyId}|${config.bucketName}`;
  if (cached?.key === key) return cached.client;

  const client = new S3Client({
    region: "auto",
    endpoint: config.endpoint,
    forcePathStyle: true,
    maxAttempts: 2,
    credentials: {
      accessKeyId: config.accessKeyId,
      secretAccessKey: config.secretAccessKey,
    },
  });
  cached = { key, client };
  return client;
}
```

Create `src/lib/receipt-storage.ts`:

```ts
import "server-only";

import {
  DeleteObjectCommand,
  GetObjectCommand,
  PutObjectCommand,
} from "@aws-sdk/client-s3";
import { resolveR2Config } from "@/lib/r2/config.mjs";
import { getReceiptStorageClient } from "@/lib/r2/client";

export type ReceiptStorage = {
  putObject(
    key: string,
    bytes: Uint8Array,
    contentType: string,
  ): Promise<void>;
  getObject(key: string): Promise<Uint8Array | null>;
  deleteObject(key: string): Promise<void>;
};

export function createReceiptStorage(): ReceiptStorage | null {
  const config = resolveR2Config();
  const client = getReceiptStorageClient();
  if (!config || !client) return null;

  return {
    async putObject(key, bytes, contentType) {
      await client.send(
        new PutObjectCommand({
          Bucket: config.bucketName,
          Key: key,
          Body: bytes,
          ContentType: contentType,
          CacheControl: "private, no-store",
        }),
      );
    },
    async getObject(key) {
      try {
        const response = await client.send(
          new GetObjectCommand({ Bucket: config.bucketName, Key: key }),
        );
        if (!response.Body) return null;
        return await response.Body.transformToByteArray();
      } catch (error) {
        if ((error as { name?: string }).name === "NoSuchKey") return null;
        throw error;
      }
    },
    async deleteObject(key) {
      await client.send(
        new DeleteObjectCommand({ Bucket: config.bucketName, Key: key }),
      );
    },
  };
}
```

```js
import { createHash, randomUUID } from "node:crypto";
import {
  buildReceiptObjectKey,
  receiptRequirement,
} from "./receipt-rules.mjs";

export async function runReceiptEntry(input, deps, commit) {
  const { storage, validateReceipt, newId = randomUUID } = deps;
  const requirement = receiptRequirement(
    input.paymentMethod,
    input.paymentStatus,
    {
      hasReceipt: input.hasReceipt,
      allowLegacyMethod: input.allowLegacyMethod,
    },
  );

  if (requirement === "unsupported") {
    return { kind: "error", notice: "invalid-request" };
  }

  let prepared = null;
  if (requirement === "required") {
    if (!input.file) return { kind: "error", notice: "receipt-required" };
    if (!storage) {
      return { kind: "error", notice: "receipt-storage-unavailable" };
    }

    const bytes = new Uint8Array(await input.file.arrayBuffer());
    const validated = validateReceipt(
      input.file.name,
      input.file.type,
      bytes,
    );
    if (!validated) return { kind: "error", notice: "receipt-invalid" };

    const receiptId = newId();
    prepared = {
      receiptId,
      objectKey: buildReceiptObjectKey({
        scope: input.scope,
        targetId: input.targetId,
        receiptId,
        contentType: validated.contentType,
      }),
      originalFilename: validated.filename,
      contentType: validated.contentType,
      sizeBytes: bytes.byteLength,
      sha256: createHash("sha256").update(bytes).digest("hex"),
    };

    try {
      await storage.putObject(
        prepared.objectKey,
        bytes,
        prepared.contentType,
      );
    } catch {
      return { kind: "error", notice: "receipt-upload-failed" };
    }
  } else if (input.file) {
    return { kind: "error", notice: "receipt-not-allowed" };
  }

  const result = await commit(prepared);

  if (result.kind === "error") {
    if (prepared) {
      await storage.deleteObject(prepared.objectKey).catch(() => undefined);
    }
    return {
      kind: "error",
      notice: "operation-failed",
      error: result.error,
    };
  }

  if (prepared && (result.deduplicated || result.id !== input.targetId)) {
    await storage.deleteObject(prepared.objectKey).catch(() => undefined);
  }

  return { kind: "ok", id: result.id, deduplicated: result.deduplicated };
}
```

```ts
import { createHash } from "node:crypto";
import { getR2StorageAdapter } from "@/lib/receipt-storage";
import { createSupabaseServerClient } from "@/lib/supabase/server";

export async function GET(
  _request: NextRequest,
  { params }: { params: Promise<{ receiptId: string }> },
) {
  const { receiptId } = await params;
  if (!receiptId || !/^[0-9a-f-]{36}$/i.test(receiptId)) {
    return new NextResponse("Invalid receipt ID", { status: 400 });
  }

  const supabase = await createSupabaseServerClient();
  const { data: authData, error: authError } = await supabase.auth.getUser();
  if (authError || !authData.user) {
    return new NextResponse("Unauthorized", { status: 401 });
  }

  // 1. Query metadata through security-definer helper
  const { data: metaRows, error: metaError } = await supabase.rpc(
    "get_finance_receipt_download",
    { p_receipt_id: receiptId },
  );

  if (metaError || !metaRows || metaRows.length === 0) {
    return new NextResponse("Receipt not found or access denied", { status: 404 });
  }

  const meta = metaRows[0];
  const storage = getR2StorageAdapter();
  if (!storage) {
    return new NextResponse("Receipt storage unavailable", { status: 503 });
  }

  // 2. Fetch object bytes from R2
  let objectResult;
  try {
    objectResult = await storage.getObject(meta.object_key);
  } catch {
    return new NextResponse("Failed to retrieve receipt from storage", { status: 503 });
  }

  if (!objectResult) {
    return new NextResponse("Receipt object not found in storage", { status: 404 });
  }

  // 3. Verify SHA-256 and byte length integrity
  if (objectResult.bytes.byteLength !== meta.size_bytes) {
    return new NextResponse("Receipt size mismatch", { status: 502 });
  }

  const calculatedHash = createHash("sha256")
    .update(objectResult.bytes)
    .digest("hex");

  if (calculatedHash !== meta.sha256) {
    return new NextResponse("Receipt digest verification failed", { status: 502 });
  }

  // 4. Return as attachment with security headers
  const sanitizedFilename = meta.original_filename.replace(/["\r\n\\]/g, "_");

  return new Response(Buffer.from(objectResult.bytes), {
    status: 200,
    headers: {
      "Content-Type": meta.content_type,
      "Content-Length": meta.size_bytes.toString(),
      "Content-Disposition": `attachment; filename="${sanitizedFilename}"`,
      "Cache-Control": "private, no-store",
      "X-Content-Type-Options": "nosniff",
      "Content-Security-Policy": "sandbox",
      "Cross-Origin-Resource-Policy": "same-origin",
      "X-Robots-Tag": "noindex",
    },
  });
}
```

```ts
import { type NextRequest, NextResponse } from "next/server";
import { createHash, randomUUID } from "node:crypto";
import { validateFinanceReceiptUpload } from "@/lib/finance-receipt-validation";
import { buildReceiptObjectKey } from "@/lib/receipt-rules.mjs";
import { getR2StorageAdapter } from "@/lib/receipt-storage";
import { createSupabaseServerClient } from "@/lib/supabase/server";

export async function POST(request: NextRequest) {
  const supabase = await createSupabaseServerClient();
  const { data: authData, error: authError } = await supabase.auth.getUser();
  if (authError || !authData.user) {
    return NextResponse.redirect(new URL("/?notice=sign-in", request.url));
  }

  const formData = await request.formData();
  const scope = formData.get("scope") as string | null;
  const targetId = formData.get("target_id") as string | null;
  const file = formData.get("file") as File | null;
  const returnUrl = (formData.get("return_url") as string | null) || "/finances";

  if (!scope || !targetId || !file || !["club", "event", "event_ticket"].includes(scope)) {
    return NextResponse.redirect(new URL(`${returnUrl}?notice=invalid-request`, request.url));
  }

  const storage = getR2StorageAdapter();
  if (!storage) {
    return NextResponse.redirect(
      new URL(`${returnUrl}?notice=receipt-storage-unavailable`, request.url),
    );
  }

  const bytes = new Uint8Array(await file.arrayBuffer());
  const validated = validateFinanceReceiptUpload(file.name, file.type, bytes);
  if (!validated) {
    return NextResponse.redirect(new URL(`${returnUrl}?notice=receipt-invalid`, request.url));
  }

  const receiptId = randomUUID();
  const objectKey = buildReceiptObjectKey({
    scope: scope as "club" | "event" | "event_ticket",
    targetId,
    receiptId,
    contentType: validated.contentType,
  });

  const sha256 = createHash("sha256").update(bytes).digest("hex");

  // 1. Upload to R2 first
  try {
    await storage.putObject(objectKey, bytes, validated.contentType);
  } catch {
    return NextResponse.redirect(
      new URL(`${returnUrl}?notice=receipt-upload-failed`, request.url),
    );
  }

  // 2. Call DB attach RPC
  const { error: rpcError } = await supabase.rpc("attach_finance_receipt", {
    p_scope: scope,
    p_target_id: targetId,
    p_receipt_id: receiptId,
    p_object_key: objectKey,
    p_original_filename: validated.filename,
    p_content_type: validated.contentType,
    p_size_bytes: bytes.byteLength,
    p_sha256: sha256,
  });

  if (rpcError) {
    await storage.deleteObject(objectKey).catch(() => undefined);
    return NextResponse.redirect(new URL(`${returnUrl}?notice=operation-failed`, request.url));
  }

  return NextResponse.redirect(new URL(`${returnUrl}?notice=receipt-attached`, request.url));
}
```

```tsx
import React, { useEffect, useRef, useState } from "react";
import { Download, ChevronLeft, ChevronRight, ZoomIn, ZoomOut, X } from "lucide-react";

interface ReceiptViewerModalProps {

  filename: string;

export const ReceiptViewerModal: React.FC<ReceiptViewerModalProps> = ({
  receiptId,
  filename,
  contentType,
  onClose,
}) => {
  const [imageUrl, setImageUrl] = useState<string | null>(null);
  const [pdfDoc, setPdfDoc] = useState<any>(null);
  const [pageNum, setPageNum] = useState(1);
  const [numPages, setNumPages] = useState(1);
  const [scale, setScale] = useState(1.0);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<string | null>(null);

  const canvasRef = useRef<HTMLCanvasElement | null>(null);
  const downloadUrl = `/api/receipts/${receiptId}`;

  // Image handling via Object URL
  useEffect(() => {
    if (contentType.startsWith("image/")) {
      let active = true;
      let objectUrl: string | null = null;

      fetch(downloadUrl)
        .then((res) => {
          if (!res.ok) throw new Error("Failed to load receipt image");
          return res.blob();
        })
        .then((blob) => {
          if (active) {
            objectUrl = URL.createObjectURL(blob);
            setImageUrl(objectUrl);
            setLoading(false);
          }
        })
        .catch((err) => {
          if (active) {
            setError(err.message || "Failed to load image");
            setLoading(false);
          }
        });

      return () => {
        active = false;
        if (objectUrl) URL.revokeObjectURL(objectUrl);
      };
    }
  }, [downloadUrl, contentType]);

  // PDF handling via PDF.js on canvas
  useEffect(() => {
    if (contentType === "application/pdf") {
      let active = true;
      (async () => {
        try {
          const pdfjs = await import("pdfjs-dist");
          pdfjs.GlobalWorkerOptions.workerSrc = new URL(
            "pdfjs-dist/build/pdf.worker.min.mjs",
            import.meta.url,
          ).toString();

          const doc = await pdfjs.getDocument(downloadUrl).promise;
          if (active) {
            setPdfDoc(doc);
            setNumPages(doc.numPages);
            setLoading(false);
          }
        } catch (err: any) {
          if (active) {
            setError(err.message || "Failed to parse PDF receipt");
            setLoading(false);
          }
        }
      })();

      return () => {
        active = false;
      };
    }
  }, [downloadUrl, contentType]);

  // Render PDF page to canvas
  useEffect(() => {
    if (pdfDoc && canvasRef.current) {
      let renderTask: any = null;
      pdfDoc.getPage(pageNum).then((page: any) => {
        const viewport = page.getViewport({ scale });
        const canvas = canvasRef.current;
        if (!canvas) return;

        canvas.height = viewport.height;
        canvas.width = viewport.width;

        const ctx = canvas.getContext("2d");
        if (!ctx) return;

        renderTask = page.render({ canvasContext: ctx, viewport });
      });

      return () => {
        if (renderTask) renderTask.cancel();
      };
    }
  }, [pdfDoc, pageNum, scale]);

  return (
    <div className="fixed inset-0 z-50 flex items-center justify-center bg-black/60 p-4 backdrop-blur-sm">
      <div className="relative flex max-h-[90vh] w-full max-w-4xl flex-col rounded-xl bg-white shadow-2xl overflow-hidden">
        {/* Header */}
        <div className="flex items-center justify-between border-b px-4 py-3 bg-stone-50">
          <div className="truncate pr-4 font-semibold text-stone-800">{filename}</div>
          <div className="flex items-center gap-2">
            <a
              href={downloadUrl}
              download={filename}
              className="inline-flex items-center gap-1 rounded bg-stone-200 px-3 py-1.5 text-xs font-medium text-stone-700 hover:bg-stone-300"
            >
              <Download className="h-4 w-4" />
              Download
            </a>
            <button
              type="button"
              onClick={onClose}
              className="rounded p-1 text-stone-500 hover:bg-stone-200 hover:text-stone-800"
            >
              <X className="h-5 w-5" />
            </button>
          </div>
        </div>

        {/* Content body */}
        <div className="flex flex-1 items-center justify-center overflow-auto p-4 bg-stone-100 min-h-[300px]">
          {loading && <div className="text-sm text-stone-500">Loading receipt…</div>}
          {error && (
            <div className="text-center text-sm text-red-600">
              <p>{error}</p>
              <a href={downloadUrl} download className="mt-2 inline-block font-semibold underline">
                Download file directly
              </a>
            </div>
          )}

          {imageUrl && (
            <img
              src={imageUrl}
              alt={filename}
              className="max-h-[75vh] max-w-full rounded object-contain shadow"
            />
          )}

          {contentType === "application/pdf" && !error && (
            <canvas ref={canvasRef} className="max-h-[75vh] shadow rounded bg-white" />
          )}
        </div>

        {/* PDF controls footer */}
        {contentType === "application/pdf" && !error && !loading && (
          <div className="flex items-center justify-between border-t px-4 py-2 bg-stone-50 text-xs">
            <div className="flex items-center gap-1">
              <button
                type="button"
                disabled={pageNum <= 1}
                onClick={() => setPageNum((p) => Math.max(1, p - 1))}
                className="rounded p-1 hover:bg-stone-200 disabled:opacity-40"
              >
                <ChevronLeft className="h-4 w-4" />
              </button>
              <span>
                Page {pageNum} of {numPages}
              </span>
              <button
                type="button"
                disabled={pageNum >= numPages}

              >
                <ChevronRight className="h-4 w-4" />
```

```js
import assert from "node:assert/strict";
import { describe, it } from "node:test";

describe("Orphan receipt sweep reconciliation", () => {
  function findOrphanKeys(s3Keys, dbKeys, cutoffDate) {
    const validDbKeys = new Set(dbKeys);
    return s3Keys
      .filter((item) => !validDbKeys.has(item.key))
      .filter((item) => new Date(item.lastModified) < cutoffDate)
      .map((item) => item.key);
  }

  it("identifies unreferenced S3 keys older than cutoff as orphans", () => {
    const cutoff = new Date(Date.now() - 2 * 60 * 60 * 1000);
    const s3 = [
      { key: "receipts/club/1/a.pdf", lastModified: new Date(Date.now() - 3 * 3600 * 1000).toISOString() },
      { key: "receipts/club/2/b.pdf", lastModified: new Date(Date.now() - 1000).toISOString() },
    ];
    const db = ["receipts/club/2/b.pdf"];

    const orphans = findOrphanKeys(s3, db, cutoff);
    assert.deepEqual(orphans, ["receipts/club/1/a.pdf"]);
```

Create `scripts/receipt-orphan-sweep.mjs`:

```js
import { S3Client, ListObjectsV2Command, DeleteObjectCommand } from "@aws-sdk/client-s3";
import { createClient } from "@supabase/supabase-js";

const isDryRun = process.argv.includes("--dry-run");
const olderThanHours = 2;
const cutoffTime = new Date(Date.now() - olderThanHours * 60 * 60 * 1000);

const accountId = process.env.R2_ACCOUNT_ID;
const accessKeyId = process.env.R2_ACCESS_KEY_ID;
const secretAccessKey = process.env.R2_SECRET_ACCESS_KEY;
const bucketName = process.env.R2_BUCKET_NAME;
const endpoint = process.env.R2_ENDPOINT || (accountId ? `https://${accountId}.r2.cloudflarestorage.com` : null);

if (!accessKeyId || !secretAccessKey || !bucketName || !endpoint) {
  console.error("Missing R2 configuration in environment.");
  process.exit(1);
}

const supabaseUrl = process.env.NEXT_PUBLIC_SUPABASE_URL || "http://127.0.0.1:54321";
const supabaseKey = process.env.SUPABASE_SECRET_KEY || process.env.SUPABASE_SERVICE_ROLE_KEY;

if (!supabaseKey) {
  console.error("Missing SUPABASE_SECRET_KEY / SUPABASE_SERVICE_ROLE_KEY.");
  process.exit(1);
}

const s3 = new S3Client({
  region: "auto",
  endpoint,
  credentials: { accessKeyId, secretAccessKey },
});

const supabase = createClient(supabaseUrl, supabaseKey);

async function runSweep() {
  console.log(`Starting R2 receipt orphan sweep (dryRun: ${isDryRun}, cutoff: ${cutoffTime.toISOString()})...`);

  // 1. Fetch all DB object keys
  const { data: dbRows, error: dbError } = await supabase
    .from("finance_receipts")
    .select("object_key");

  if (dbError) {
    console.error("Failed to query finance_receipts:", dbError.message);
    process.exit(1);
  }

  const dbKeys = new Set((dbRows || []).map((r) => r.object_key));
  console.log(`Found ${dbKeys.size} valid receipt keys in database.`);

  // 2. Scan R2 prefix receipts/
  let continuationToken = undefined;
  let scannedCount = 0;
  let orphanCount = 0;

  do {
    const listRes = await s3.send(
      new ListObjectsV2Command({
        Bucket: bucketName,
        Prefix: "receipts/",
        ContinuationToken: continuationToken,
      }),
    );

    for (const obj of listRes.Contents || []) {
      scannedCount++;
      if (!dbKeys.has(obj.Key) && obj.LastModified && obj.LastModified < cutoffTime) {
        orphanCount++;
        console.log(`[ORPHAN] ${obj.Key} (modified ${obj.LastModified.toISOString()})`);
        if (!isDryRun) {
          await s3.send(new DeleteObjectCommand({ Bucket: bucketName, Key: obj.Key }));
          console.log(`  Deleted ${obj.Key}`);
        }
      }
    }

    continuationToken = listRes.NextContinuationToken;
  } while (continuationToken);

  console.log(`Sweep complete: scanned ${scannedCount} objects, found ${orphanCount} orphans.`);
}

runSweep().catch((err) => {
  console.error("Sweep failed:", err);
  process.exit(1);
});
```
